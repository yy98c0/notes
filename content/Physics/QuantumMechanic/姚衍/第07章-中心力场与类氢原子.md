> [!definition] 空间量子化（space quantization）
> 在微观尺度内，有些物理量（如：能量、角动量、磁偶极矩、力…），在空间中的一特定方向（如：外加磁场、外加电场、两原子核的连线…）上，仅能携带特别的不连续值，此性质称为空间量子化。

$$|+\rangle_x = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 \ 1 \end{pmatrix} \quad \text{或} \quad |+\rangle_x = \frac{1}{\sqrt{2}} \left[ \begin{pmatrix} 1 \ 0 \end{pmatrix} + \begin{pmatrix} 0 \ 1 \end{pmatrix} \right] = \frac{1}{\sqrt{2}} (|+\rangle + |-\rangle)
$$

及

$$|-\rangle_x = \frac{1}{\sqrt{2}} \begin{pmatrix} 1 \ -1 \end{pmatrix} \quad \text{或} \quad |-\rangle_x = \frac{1}{\sqrt{2}} \left[ \begin{pmatrix} 1 \ 0 \end{pmatrix} - \begin{pmatrix} 0 \ 1 \end{pmatrix} \right] = \frac{1}{\sqrt{2}} (|+\rangle - |-\rangle)
$$

Chapter 7 氢原子

量子力学初期很成功的地方，在于它能正确清楚地描述原子光谱、塞曼效应（Zeeman effect）、斯塔克效应（Stark effect）、以及许多分子与离子之键结问题。这些现象都可由简单的原子——氢原子之波函数、与对应能级及各量子数（或本征值）出发，来近似模拟和推广处理，故此章我们将讨论如何以量子力学，来描述氢原子的行为。

### 7.1 二相互作用的粒子所成的系统（二体问题）

前面第五章我们所讨论的，都是单一质点在各种不同环境（或势能）下，所呈现的特殊能级和出现概率。然氢原子为含有原子核及核外电子的二质点系统，我们须先将它化为二个单一质点的独立系统，再来处理。现先从经典物理出发。

### (一) 经典力学的观点

两粒子 $m_1$、$m_2$，若其相互作用势能为 $V(\vec{r}_1 - \vec{r}_2)$，则此系统的动力变量——拉格朗日量为：

$L(\vec{r}_1, \dot{\vec{r}}_1; \vec{r}_2, \dot{\vec{r}}_2) = T - V = \frac{1}{2} m_1 \dot{\vec{r}}_1^2 + \frac{1}{2} m_2 \dot{\vec{r}}_2^2 - V(\vec{r}_1 - \vec{r}_2) \quad (7.1)$

引入质心位置 $\bar{R}$，与相对位置 $\vec{r}$，如下：

$\bar{R} = \frac{m_1 \vec{r}_1 + m_2 \vec{r}_2}{m_1 + m_2}, \quad \vec{r} = \vec{r}_1 - \vec{r}_2 \quad (7.2)$

则

$\bar{r}_1 = \bar{R} + \frac{m_2}{m_1 + m_2} \vec{r}, \quad \bar{r}_2 = \bar{R} - \frac{m_1}{m_1 + m_2} \vec{r} \quad (7.3)$

## Ch7-2 建立氢原子的波动方程

故一旦获知 $\bar{R}$ 与 $\bar{r}$ 的运动行为，也就可得到 $\bar{r}_1$ 与 $\bar{r}_2$ 的运动情形。二体问题也由此可获解决。

![](Physics/QuantumMechanic/姚衍/images/Ch7-2_page0_0.jpg)

<center>图7.1</center>  

此时，二质点 $m_1$、$m_2$ 原来的拉格朗日量，亦可等同写为：

$L(\bar{R},\dot{\bar{R}};\bar{r},\dot{\bar{r}}) = \frac{1}{2} M\dot{\bar{R}}^2 +\frac{1}{2} m\dot{\bar{r}}^2 -V(\bar{r}) \quad (7.4)$

其中

$M = m_1 + m_2, \quad m = \frac{m_1m_2}{m_1 + m_2} \quad (7.5)$

可视为二虚拟质点之质量，并分别称为总质量与约化质量（reduced mass）。

另一方面，若以动量取代速度，

$\bar{p}_1 = m_1\dot{\bar{r}}_1, \quad \bar{p}_2 = m_2\dot{\bar{r}}_2 \quad (7.6)$

则总动量与相对动量分别为

$\bar{P}_G = M\dot{\bar{R}} = m_1\dot{\bar{r}}_1 + m_2\dot{\bar{r}}_2 = \bar{p}_1 + \bar{p}_2 \quad (7.7)$

$\bar{p} = m\dot{\bar{r}} = \frac{m_2\bar{p}_1 - m_1\bar{p}_2}{m_1 + m_2} \quad (7.8)$

而系统的哈密顿量（或总能量）：

$$

\begin{aligned}
H(\bar{R},\bar{P}\_G;\bar{r},\bar{p}) &= T + V \\
&= \frac{1}{2} M\left(\frac{\bar{P}\_G}{M}\right)^2 +\frac{1}{2} m\left(\frac{\bar{p}}{m}\right)^2 +V(\bar{r}) = \frac{\bar{P}\_G^2}{2M} +\frac{\bar{p}^2}{2m} +V(\bar{r}) \quad (7.9)
\end{aligned}

$$

其中 $\bar{R}$、$\bar{P}_G$、$\bar{r}$、$\bar{p}$ 彼此互为独立变量，若解出下列的运动方程：

$$\left{ \begin{array}{l}\dot{P}_{G i} = -\frac{\partial H}{\partial R_i}\Rightarrow \dot{\bar{P}}_G = -\nabla_R H = 0\ (\text{质心的运动}; \text{对自由粒子而言}, \bar{P}_G = \text{常数})\ \displaystyle \dot{p}_i = -\frac{\partial H}{\partial r_i}\Rightarrow \dot{\bar{p}} = -\nabla H = -\nabla V(r)\ (\text{粒子之间的相对运动}) \end{array} \right.
$$

就可知 $\bar{R}$ 和 $\bar{r}$ 的运动情形。图7-2表示，如何将二体问题 $m_1$ 与 $m_2$ 转换为两个单一质点 $M$ 与 $m$ 问题。

<center>图7.2</center>  

进一步而言，在质心坐标系中（质点 $M$ 静止）

$\bar{P}_G = 0, \quad \text{或} \quad \bar{R} = \text{定值} \quad (7.10)$

$H(\bar{R},\bar{P}_G;\bar{r},\bar{p}) = H(\bar{r},\bar{p}) = \frac{\bar{p}^2}{2m} +V(\bar{r}) \quad (7.11)$

两个相互作用粒子的运动，遂可简化为携带约化质量 $m$ 之单一虚拟质点的运动，即仅须考虑坐标 $\bar{r}$ 上质点 $m$ 之运动。

### 7.2 单一质点在中心力势能作用下的定态

一质点在中心力势能 $V(\bar{r}) = V(r,\theta ,\phi) = V(r)$ 下运动，代表此质点所受之势能，只与质点到原点或力心的距离大小有关，而与方向角度无关。由于此时质点角动量 $\bar{L}$ 之变率为

$$
\begin{array}{l}\frac{d\bar{L}}{dt} = \frac{d}{dt} (\bar{r}\times \bar{p}) = \frac{d\bar{r}}{dt}\times \bar{p} +\bar{r}\times \frac{d\bar{p}}{dt}\\ \displaystyle = \bar{v}\times \bar{p} +\bar{r}\times \frac{d\bar{p}}{dt} = \bar{r}\times \bar{F} = -\bar{r}\times \nabla V(r) = -\bar{r}\times \frac{\partial V}{\partial r}\bar{e}_r = 0 \end{array} \quad (7.19)
$$

故角动量 $\bar{L} =$ 常数，亦即质点之 $\bar{r}$ 和 $\bar{p}$ 永远在同一平面上，因为此平面之法线，即为角动量 $\bar{L}$ ，维持恒常不变。

> [!proposition] 中心力场中的角动量守恒
> 一质点若受中心力场作用，必有角动量守恒，以及运动轨迹为一平面运动。

在中心力场作用下，此质点之能量本征值方程，由式(7.18)得

$\left[\frac{-\hbar^2}{2m}\nabla^2 +V(r)\right]\Psi (\bar{r}) = E\Psi (\bar{r}) \quad (7.20)$

其中

$\nabla^2 = \frac{1}{r^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{r^2} \left(\frac{\partial^2}{\partial\theta^2} +\frac{1}{\tan\theta}\frac{\partial}{\partial\theta} +\frac{1}{\sin^2\theta}\frac{\partial^2}{\partial\phi^2}\right) \quad (7.21)$

又由角动量算符 $\hat{L}^2$ 之定义式(6.62)，故

$\left[\frac{-\hbar^2}{2mr^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{2mr^2}\hat{L}^2 +V(r)\right]\Psi (r,\theta ,\phi) = E\Psi (r,\theta ,\phi) \quad (7.22)$

因 $\hat{L}^2$ 和 $\hat{L}_z = - i\hbar \frac{\partial}{\partial\phi}$ 仅为 $\theta$ 和 $\phi$ 的函数，所以任何仅与 $r$ 有关，而与 $\theta ,\phi$ 无关的算符，皆可与它们对易，即

$[\hat{H},\hat{L}^2 ] = \left[\frac{-\hbar^2}{2mr^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{2mr^2}\hat{L}^2 +V(r),\hat{L}^2 \right] = 0 \quad (7.23)$

同理， $[\hat{H},\hat{L}_z ] = 0$ 。

### （二）量子力学的观点

将经典力学中的能量：

$H(\vec{R},\vec{P}_G;\vec{r},\vec{p}) = \frac{\vec{P}_G^2}{2M} +\frac{\vec{p}^2}{2m} +V(\vec{r}) \quad (7.12)$

由量子力学公设二，代换成算符后，而成为

$\hat{H} = \frac{\hat{P}_G^2}{2M} +\frac{\hat{p}^2}{2m} +V(\hat{r}) = \hat{H}_G + \hat{H}_r \quad (7.13)$

其中

$\hat{H}_G = \frac{\hat{P}_G^2}{2M}, \quad \hat{H}_r = \frac{\hat{p}^2}{2m} +V(\hat{r}) \quad (7.14)$

若不考虑总质量为 $m_1 + m_2 = M$ 质心之直线运动，或仅讨论在质心坐标系统 $\vec{P}_G = 0$ ，则

$\hat{H} = \hat{H}_r = \frac{\hat{p}^2}{2m} +V(\hat{r}) \quad (7.15)$

其本征值方程为

$\left[\frac{\hat{p}^2}{2m} +V(\hat{r})\right]|\Psi \rangle = E|\Psi \rangle \quad (7.16)$

投影在相对位置空间 $\langle \vec{r} |$ 上，得

$\left[\frac{-\hbar^2}{2m}\nabla^2 +V(r)\right]\langle \vec{r} |\Psi \rangle = E\langle \vec{r} |\Psi \rangle \quad (7.17)$

或

$\left[\frac{-\hbar^2}{2m}\nabla^2 +V(r)\right]\Psi (\vec{r}) = E\Psi (\vec{r}) \quad (7.18)$

此式有如携带约化质量为 $m$ 之单一质点，在原先相互作用势能 $V(\hat{r})$ 作用下的本征值问题，即二体（质点 $m_1$ 与 $m_2$ ）问题已简化为一体（质点 $m$ ）问题。

### 7.3 类氢原子 $(\mathrm{H}, \mathrm{Li}^{+}, \mathrm{Be}^{2+}, \mathrm{B}^{3+}, \dots)$

利用二体问题之处理方法与中心力场之特性，现在我们可探讨氢原子系统之能量与行为。氢原子或类氢原子(核外仅有单一电子)，包含两个部分，一个是带有 $Zq$ 正电荷之原子核，另一个是核外之单一电子。其相互作用的库仑力为

$\bar{F} = \frac{1}{4\pi \epsilon_0} \frac{q_1 q_2}{r^2} \bar{e}_r = -\nabla V(r) \quad (7.30)$

对应的相互作用库仑势能则为

$V(r) = \frac{1}{4\pi \epsilon_0} \frac{(Zq)(-q)}{r} = -\frac{Ze^2}{r} \quad (7.31)$

其中

$e^2 = \frac{q^2}{4\pi \epsilon_0}, \quad q = 1.6 \times 10^{-19}\ \mathrm{C}$

若不考虑总质量为 $M$ (原子核质量与电子之质量和 $= m_N + m_e$ )，之直线运动所携带的动能，则在此质心坐标下，能量本征值方程，由式(7.20) (为方便起见底下均设 $Z=1$，对类氢原子仅需以 $Ze^2$ 取代 $e^2$ 即可)

$\left[-\frac{\hbar^2}{2m} \nabla^2 - \frac{e^2}{r}\right] \Psi(\bar{r}) = E \Psi(\bar{r}) \quad (7.32)$

其中

$\bar{r} = \bar{r}_1 - \bar{r}_2, \quad m = \frac{m_e m_N}{m_e + m_N} \quad (7.33)$

$\bar{r}_1$、$\bar{r}_2$ 分别为电子、与原子核之位置向量。则类氢原子之二体问题（原子核与电子）简化为携带约化质量 $m$（既不是原子核，也不是电子）之一体问题。又因库仑势能为一中心力势能，故由式(7.28)，其解含有径向与角度部分。而角度部分必为球谐函数 $Y_\ell^m(\theta, \varphi)$，而径向部分 $R(r)$ 则满足

$\left[-\frac{\hbar^2}{2mr^2} \frac{d}{dr} \left(r^2 \frac{d}{dr}\right) + \frac{\hbar^2}{2mr^2} \ell(\ell+1) - \frac{e^2}{r}\right] R(r) = ER(r) \quad (7.34)$

且因在无限远处找到质点 $m$ 之概率为 0，故在 $r \to \infty$ 时，径向部分需满足边界条件

$R(r \to \infty) = 0 \quad (7.35)$

### 7.2 单一质点在中心力势能作用下的定态

一质点在中心力势能 $V(\bar{r}) = V(r,\theta ,\phi) = V(r)$ 下运动，代表此质点所受之势能，只与质点到原点或力心的距离大小有关，而与方向角度无关。由于此时质点角动量 $\bar{L}$ 之变率为

$$

在中心力场作用下，此质点之能量本征值方程，由式(7.18)得

$\left[\frac{-\hbar^2}{2m}\nabla^2 +V(r)\right]\Psi (\bar{r}) = E\Psi (\bar{r}) \quad (7.20)$

其中

$\nabla^2 = \frac{1}{r^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{r^2} \left(\frac{\partial^2}{\partial\theta^2} +\frac{1}{\tan\theta}\frac{\partial}{\partial\theta} +\frac{1}{\sin^2\theta}\frac{\partial^2}{\partial\phi^2}\right) \quad (7.21)$

又由角动量算符 $\hat{L}^2$ 之定义式(6.62)，故

$\left[\frac{-\hbar^2}{2mr^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{2mr^2}\hat{L}^2 +V(r)\right]\Psi (r,\theta ,\phi) = E\Psi (r,\theta ,\phi) \quad (7.22)$

因 $\hat{L}^2$ 和 $\hat{L}_z = - i\hbar \frac{\partial}{\partial\phi}$ 仅为 $\theta$ 和 $\phi$ 的函数，所以任何仅与 $r$ 有关，而与 $\theta ,\phi$ 无关的算符，皆可与它们对易，即

$[\hat{H},\hat{L}^2 ] = \left[\frac{-\hbar^2}{2mr^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{2mr^2}\hat{L}^2 +V(r),\hat{L}^2 \right] = 0 \quad (7.23)$

同理， $[\hat{H},\hat{L}_z ] = 0$ 。

由数学基本定理 II，当

$[\hat{H}, \hat{L}^2] = [\hat{H}, \hat{L}_z] = [\hat{L}^2, \hat{L}_z] = 0 \quad (7.24)$

$\hat{H}$、$\hat{L}^2$ 和 $\hat{L}_z$ 分享有共同的本征向量 $\Psi_{n\ell m}(r, \theta, \varphi)$，并具有对应的本征值，即

$$
\begin{aligned} \hat{H} \Psi_{n\ell m}(r, \theta, \varphi) &= E_n \Psi_{n\ell m}(r, \theta, \varphi) \\ \hat{L}^2 \Psi_{n\ell m}(r, \theta, \varphi) &= \ell (\ell + 1) \hbar^2 \Psi_{n\ell m}(r, \theta, \varphi) \\ \hat{L}_z \Psi_{n\ell m}(r, \theta, \varphi) &= m\hbar \Psi_{n\ell m}(r, \theta, \varphi) \end{aligned} \quad (7.25) \quad (7.26) \quad (7.27)
$$

由式(6.69)与(6.70)，已知 $\hat{L}^2$ 和 $\hat{L}_z$ 之本征值方程之解为 $Y_\ell^m(\theta, \varphi)$，故质点在中心力势能下的定态函数，可分为径向距离部分与角度部分，

$\Psi_{n\ell m}(r, \theta, \varphi) = R(r) Y_\ell^m(\theta, \varphi) \quad (7.28)$

其中径向部分 $R(r)$ 须满足

$\left[ \frac{-\hbar^2}{2mr^2} \frac{d}{dr} \left(r^2 \frac{d}{dr}\right) + \frac{\hbar^2}{2mr^2} \ell(\ell+1) + V(r) \right] R(r) = ER(r) \quad (7.29)$

而角度部分，永远为球谐函数 $Y_\ell^m(\theta, \varphi)$，不须重新再去解它。

### 7.3 类氢原子 $(\mathrm{H}, \mathrm{Li}^+, \mathrm{Be}^{2+}, \mathrm{B}^{3+}, \dots)$

利用二体问题之处理方法与中心力场之特性，现在我们可探讨氢原子系统之能量与行为。氢原子或类氢原子(核外仅有单一电子)，包含两个部分，一个是带有 $Zq$ 正电荷之原子核，另一个是核外之单一电子。其相互作用的库仑力为

$\vec{F} = \frac{1}{4\pi\epsilon_0} \frac{q_1 q_2}{r^2} \vec{e}_r = -\nabla V(r) \quad (7.30)$

对应的相互作用库仑势能则为

$V(r) = \frac{1}{4\pi\epsilon_0} \frac{(Zq)(-q)}{r} = -\frac{Ze^2}{r} \quad (7.31)$

其中

$e^2 = \frac{q^2}{4\pi\epsilon_0}, \quad q = 1.6 \times 10^{-19}\ \mathrm{C}$

若不考虑总质量为 $M$ (原子核质量与电子之质量和 $= m_N + m_e$ )，之直线运动所携带的动能，则在此质心坐标下，能量本征值方程，由式(7.20) (为方便起见底下均设 $Z=1$，对类氢原子仅需以 $Ze^2$ 取代 $e^2$ 即可)

$\left[-\frac{\hbar^2}{2m} \nabla^2 - \frac{e^2}{r}\right] \Psi(\vec{r}) = E \Psi(\vec{r}) \quad (7.32)$

其中

$\vec{r} = \vec{r}_1 - \vec{r}_2, \quad m = \frac{m_e m_N}{m_e + m_N} \quad (7.33)$

$\vec{r}_1$、$\vec{r}_2$ 分别为电子、与原子核之位置向量。则类氢原子之二体问题（原子核与电子）简化为携带约化质量 $m$（既不是原子核，也不是电子）之一体问题。又因库仑势能为一中心力势能，故由式(7.28)，其解含有径向与角度部分。而角度部分必为球谐函数 $Y_\ell^m(\theta, \varphi)$，而径向部分 $R(r)$ 则满足

$\left[-\frac{\hbar^2}{2mr^2} \frac{d}{dr} \left(r^2 \frac{d}{dr}\right) + \frac{\hbar^2}{2mr^2} \ell(\ell+1) - \frac{e^2}{r}\right] R(r) = ER(r) \quad (7.34)$

且因在无限远处找到质点 $m$ 之概率为 0，故在 $r \to \infty$ 时，径向部分需满足边界条件

$R(r \to \infty) = 0 \quad (7.35)$

若令

$u(r) = rR(r) \quad (7.36)$

则函数 $u(r)$ 有两边界条件

$u(r = 0) = 0, \quad u(r\rightarrow \infty) = rR(r\rightarrow \infty) = 0 \quad (7.37)$

而

$\frac{d}{d r} \left(r^2 \frac{d}{d r}\right) R(r) = \frac{d}{d r} r^2 \frac{d}{d r} \frac{u(r)}{r} = \frac{d}{d r} [ru'(r) - u(r)] = ru''(r) \quad (7.38)$

故式(7.34)乘上 $2m / \hbar^2$ 后得

$-\frac{1}{r^2} \cdot ru''(r) + \frac{\ell(\ell + 1)}{r^2} R(r) - \frac{2m}{\hbar^2} \cdot \frac{e^2}{r} R(r) - \frac{2mE}{\hbar^2} R(r) = 0 \quad (7.39)$

乘上 $r$ 后得

$\left(-\frac{d^2}{dr^2} +\frac{\ell(\ell + 1)}{r^2} -\frac{2m}{\hbar^2} \frac{e^2}{r} +\frac{2m|E|}{\hbar^2}\right) u(r) = 0 \quad (7.40)$

若电子之总能量 $E > 0$ ，则电子将电离成为自由粒子，若仅讨论局限在氢原子内之电子，则其总能量 $E < 0$ ，故此处设 $E = - |E|$ 。令 $k^2 = \frac{2m|E|}{\hbar^2}$

并将 $- 1 / 4k^2$ 乘上式(7.40)，得

$\left(\frac{d^2}{d(2kr)^2} -\frac{\ell(\ell + 1)}{(2kr)^2} +\frac{me^2}{k\hbar^2} \frac{1}{2kr} -\frac{1}{4k^2} \frac{2m|E|}{\hbar^2}\right) u(r) = 0 \quad (7.41)$

现引进无量纲的参数 $\rho$ 与 $\tau$ ，设

$\rho \equiv 2kr \quad (7.42)$

$\tau^2 = \frac{1}{(ka_0)^2} = \left(\frac{me^2}{k\hbar^2}\right)^2 = \frac{2m}{\hbar^2k^2} \cdot \frac{me^4}{2\hbar^2} = \frac{1}{|E|} \cdot \frac{me^4}{2\hbar^2} = \frac{|E_0|}{|E|} \quad (7.43)$

其中 $a_0 = \hbar^2 /me^2 = 0.53\ \text{Å} =$ 玻尔半径， $|E_0| = me^4 /2\hbar^2$ 。对氢原子而言， $|E_0| = 13.6\ \mathrm{eV}$ 。而 $E$ ， $k$ 或 $\tau$ 均为待决定值。式(7.41)则可化简为

$\frac{d^2}{d\rho^2} u(\rho) - \frac{\ell(\ell + 1)}{\rho^2} u(\rho) + \left(\frac{\tau}{\rho} -\frac{1}{4}\right) u(\rho) = 0 \quad (7.44)$

## Ch7-4 氢原子能量的量子化

### 7.2 单一质点在中心力势能作用下的定态

一质点在中心力势能 $V(\bar{r}) = V(r,\theta ,\phi) = V(r)$ 下运动，代表此质点所受之势能，只与质点到原点或力心的距离大小有关，而与方向角度无关。由于此时质点角动量 $\bar{L}$ 之变率为

$$
\begin{array}{l}\frac{d\bar{L}}{dt} = \frac{d}{dt} (\bar{r}\times \bar{p}) = \frac{d\bar{r}}{dt}\times \bar{p} +\bar{r}\times \frac{d\bar{p}}{dt}\\ \displaystyle = \bar{v}\times \bar{p} +\bar{r}\times \frac{d\bar{p}}{dt} = \bar{r}\times \bar{F} = -\bar{r}\times \nabla V(r) = -\bar{r}\times \frac{\partial V}{\partial r}\bar{e}_r = 0 \end{array} \quad (7.19)
$$

故角动量 $\bar{L} =$ 常数，亦即质点之 $\bar{r}$ 和 $\bar{p}$ 永远在同一平面上，因为此平面之法线，即为角动量 $\bar{L}$ ，维持恒常不变。

> [!proposition] 中心力场中的角动量守恒
> 一质点若受中心力场作用，必有角动量守恒，以及运动轨迹为一平面运动。

在中心力场作用下，此质点之能量本征值方程，由式(7.18)得

$\left[-\frac{\hbar^2}{2m}\nabla^2 +V(r)\right]\Psi (\bar{r}) = E\Psi (\bar{r}) \quad (7.20)$

其中

$\nabla^2 = \frac{1}{r^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{r^2} \left(\frac{\partial^2}{\partial\theta^2} +\frac{1}{\tan\theta}\frac{\partial}{\partial\theta} +\frac{1}{\sin^2\theta}\frac{\partial^2}{\partial\phi^2}\right) \quad (7.21)$

又由角动量算符 $\hat{L}^2$ 之定义式(6.62)，故

$\left[-\frac{\hbar^2}{2mr^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{2mr^2}\hat{L}^2 +V(r)\right]\Psi (r,\theta ,\phi) = E\Psi (r,\theta ,\phi) \quad (7.22)$

因 $\hat{L}^2$ 和 $\hat{L}_z = - i\hbar \frac{\partial}{\partial\phi}$ 仅为 $\theta$ 和 $\phi$ 的函数，所以任何仅与 $r$ 有关，而与 $\theta ,\phi$ 无关的算符，皆可与它们对易，即

$[\hat{H},\hat{L}^2 ] = \left[\frac{-\hbar^2}{2mr^2}\frac{\partial}{\partial r} \left(r^2\frac{\partial}{\partial r}\right) + \frac{1}{2mr^2}\hat{L}^2 +V(r),\hat{L}^2 \right] = 0 \quad (7.23)$

同理， $[\hat{H},\hat{L}_z ] = 0$ 。

由数学基本定理 II，当

$[\hat{H}, \hat{L}^2] = [\hat{H}, \hat{L}_z] = [\hat{L}^2, \hat{L}_z] = 0 \quad (7.24)$

$\hat{H}$、$\hat{L}^2$ 和 $\hat{L}_z$ 分享有共同的本征向量 $\Psi_{n\ell m}(r, \theta, \varphi)$，并具有对应的本征值，即

$$
\begin{align*} \hat{H} \Psi_{n\ell m}(r, \theta, \varphi) &= E_n \Psi_{n\ell m}(r, \theta, \varphi) \tag{7.25} \\ \hat{L}^2 \Psi_{n\ell m}(r, \theta, \varphi) &= \ell (\ell + 1) \hbar^2 \Psi_{n\ell m}(r, \theta, \varphi) \tag{7.26} \\ \hat{L}_z \Psi_{n\ell m}(r, \theta, \varphi) &= m\hbar \Psi_{n\ell m}(r, \theta, \varphi) \tag{7.27} \end{align*}
$$

由式(6.69)与(6.70)，已知 $\hat{L}^2$ 和 $\hat{L}_z$ 之本征值方程之解为 $Y_\ell^m(\theta, \varphi)$，故质点在中心力势能下的定态函数，可分为径向距离部分与角度部分，

$\Psi_{n\ell m}(r, \theta, \varphi) = R(r) Y_\ell^m(\theta, \varphi) \quad (7.28)$

其中径向部分 $R(r)$ 须满足

$\left[-\frac{\hbar^2}{2mr^2} \frac{d}{dr} \left(r^2 \frac{d}{dr}\right) + \frac{\hbar^2}{2mr^2} \ell(\ell+1) + V(r)\right] R(r) = ER(r) \quad (7.29)$

而角度部分，永远为球谐函数 $Y_\ell^m(\theta, \varphi)$，不须重新再去解它。

### 7.3 类氢原子 $(\mathrm{H}, \mathrm{Li}^+, \mathrm{Be}^{2+}, \mathrm{B}^{3+}, \dots)$

利用二体问题之处理方法与中心力场之特性，现在我们可探讨氢原子系统之能量与行为。氢原子或类氢原子(核外仅有单一电子)，包含两个部分，一个是带有 $Zq$ 正电荷之原子核，另一个是核外之单一电子。其相互作用的库仑力为

$\bar{F} = \frac{1}{4\pi \epsilon_0} \frac{q_1 q_2}{r^2} \bar{e}_r = -\nabla V(r) \quad (7.30)$

对应的相互作用库仑势能则为

$V(r) = \frac{1}{4\pi \epsilon_0} \frac{(Zq)(-q)}{r} = -\frac{Ze^2}{r} \quad (7.31)$

其中

$e^2 = \frac{q^2}{4\pi \epsilon_0}, \quad q = 1.6 \times 10^{-19}\ \mathrm{C}$

若不考虑总质量为 $M$ (原子核质量与电子之质量和 $= m_N + m_e$ )，之直线运动所携带的动能，则在此质心坐标下，能量本征值方程，由式(7.20) (为方便起见底下均设 $Z=1$，对类氢原子仅需以 $Ze^2$ 取代 $e^2$ 即可)

$\left[-\frac{\hbar^2}{2m} \nabla^2 - \frac{e^2}{r}\right] \Psi(\bar{r}) = E \Psi(\bar{r}) \quad (7.32)$

其中

$\bar{r} = \bar{r}_1 - \bar{r}_2, \quad m = \frac{m_e m_N}{m_e + m_N} \quad (7.33)$

$\bar{r}_1$、$\bar{r}_2$ 分别为电子、与原子核之位置向量。则类氢原子之二体问题（原子核与电子）简化为携带约化质量 $m$ (既不是原子核，也不是电子) 之一体问题。又因库仑势能为一中心力势能，故由式(7.28)，其解含有径向与角度部分。而角度部分必为球谐函数 $Y_\ell^m(\theta, \varphi)$，而径向部分 $R(r)$ 则满足

$\left[-\frac{\hbar^2}{2mr^2} \frac{d}{dr} \left(r^2 \frac{d}{dr}\right) + \frac{\hbar^2}{2mr^2} \ell(\ell+1) - \frac{e^2}{r}\right] R(r) = ER(r) \quad (7.34)$

且因在无限远处找到质点 $m$ 之概率为 0，故在 $r \to \infty$ 时，径向部分需满足边界条件

$R(r \to \infty) = 0 \quad (7.35)$

若令

$u(r) = rR(r) \quad (7.36)$

则函数 $u(r)$ 有两边界条件

$u(r = 0) = 0, \quad u(r\rightarrow \infty) = rR(r\rightarrow \infty) = 0 \quad (7.37)$

而

$\frac{d}{d r} \left(r^{2}\frac{d}{d r}\right)R(r) = \frac{d}{d r} r^{2}\frac{d}{d r}\frac{u(r)}{r} = \frac{d}{d r} [r u^{\prime}(r) - u(r)] = r u^{\prime \prime}(r) \quad (7.38)$

故式(7.34)乘上 $2m / \hbar^{2}$ 后得

$-\frac{1}{r^{2}}\cdot r u^{\prime \prime}(r) + \frac{\ell(\ell + 1)}{r^{2}} R(r) - \frac{2m}{\hbar^{2}}\cdot \frac{e^{2}}{r} R(r) - \frac{2mE}{\hbar^{2}} R(r) = 0 \quad (7.39)$

乘上 $r$ 后得

$\left(-\frac{d^{2}}{dr^{2}} +\frac{\ell(\ell + 1)}{r^{2}} -\frac{2m}{\hbar^{2}}\frac{e^{2}}{r} +\frac{2m|E|}{\hbar^{2}}\right)u(r) = 0 \quad (7.40)$

若电子之总能量 $E > 0$ ，则电子将电离成为自由粒子，若仅讨论局限在氢原子内之电子，则其总能量 $E< 0$ ，故此处设 $E = - |E|$ 。令 $k^{2} = \frac{2m|E|}{\hbar^{2}}$ 并将 $- 1 / 4k^{2}$ 乘上式(7.40)，得

$\left(\frac{d^{2}}{d(2kr)^{2}} -\frac{\ell(\ell + 1)}{(2kr)^{2}} +\frac{me^{2}}{k\hbar^{2}}\frac{1}{2kr} -\frac{1}{4k^{2}}\frac{2m|E|}{\hbar^{2}}\right)u(r) = 0 \quad (7.41)$

现引进无量纲的参数 $\rho$ 与 $\tau$ ，设

$\rho = 2kr \quad (7.42)$

$\tau^{2} = \frac{1}{(ka_{0})^{2}} = \left(\frac{me^{2}}{k\hbar^{2}}\right)^{2} = \frac{2m}{\hbar^{2}k^{2}}\cdot \frac{me^{4}}{2\hbar^{2}} = \frac{1}{|E|}\cdot \frac{me^{4}}{2\hbar^{2}} = \frac{|E_{0}|}{|E|} \quad (7.43)$

其中 $a_{0} = \hbar^{2} / me^{2} = 0.53\ \text{Å} =$ 玻尔半径， $|E_{0}| = me^{4} / 2\hbar^{2}$ 。对氢原子而言， $|E_{0}| = 13.6\ \mathrm{eV}$ 。而 $E$ ， $k$ 或 $\tau$ 均为待决定值。式(7.41)则可化简为

$\frac{d^{2}}{d\rho^{2}} u(\rho) - \frac{\ell(\ell + 1)}{\rho^{2}} u(\rho) + \left(\frac{\tau}{\rho} -\frac{1}{4}\right)u(\rho) = 0 \quad (7.44)$

式中利用了 $2m|E| = \hbar^2 k^2$ , $\tau = \frac{me^2}{k\hbar^2}$ (7.45)

若解得本征值 $\tau$ , 即可求得能级, 或能量本征值 $E$ 。

### (一) 检视无限远处 $\rho \gg 1$ 之渐近行为:

在此情况下, 式(7.44)可近似为

$\frac{d^2}{d\rho^2} u(\rho) - \frac{1}{4} u(\rho) = 0 \quad (7.46)$

其解为 $u(\rho) = A e^{-\rho/2} + B e^{\rho/2}$ (7.47)

由边界条件式(7.37): $u(\rho \to \infty) = 0$, $e^{\rho/2}$ 之部分不可存在。故当 $\rho \to \infty$ 时,

$u(\rho) \sim e^{-\rho/2} \quad (7.48)$

### (二) 检视原点附近 $\rho \sim 0$ 之渐近行为:

在此情形下, 式(7.44)可近似为

$\frac{d^2}{d\rho^2} u(\rho) - \frac{\ell(\ell+1)}{\rho^2} u(\rho) = 0 \quad (7.49)$

试 $u(\rho) = \rho^s$, 则上式(7.49)成为

$s(s-1) \rho^{s-2} - \ell(\ell+1) \rho^{s-2} = 0 \quad (7.50)$

得 $s = \ell+1$ 或 $-\ell$, 或

$u(\rho) = C\rho^{\ell+1} + D\rho^{-\ell} \quad (7.51)$

由边界条件式(7.37): $u(\rho \to 0) = 0$, $\rho^{-\ell}$ 部分不可存在。故当 $\rho \to 0$ 时,

$u(\rho) \sim \rho^{\ell+1} \quad (7.52)$

综合以上二渐近行为, 可设

$u(\rho) = e^{-\rho/2} \rho^{\ell+1} F(\rho) \quad (7.53)$

则 $u'(\rho) = \left[\left(-\frac{1}{2}\rho + \ell + 1\right)F(\rho) + \rho F'(\rho)\right]e^{-\rho/2}\rho^\ell$ (7.54)

且

$$

\begin{align*}
u''(\rho) &= \[\rho F''(\rho) + (2\ell + 2 - \rho)F'(\rho) \\
&\quad + (-1 - \ell + \frac{\ell}{\rho} + \frac{\ell^2}{\rho} + \frac{1}{4}\rho)F(\rho)] e^{-\rho/2}\rho^\ell \tag{7.55}
\end{align*}

$$

而

$$

-\frac{\ell(\ell+1)}{\rho^2} u(\rho) = \left[-\frac{\ell(\ell+1)}{\rho} F(\rho)\right] e^{-\rho/2}\rho^\ell \quad (7.56)

$$

及

$$

\left(\frac{\tau}{\rho} - \frac{1}{4}\right)u(\rho) = \left(\frac{\tau}{\rho} - \frac{1}{4}\right)e^{-\rho/2}\rho^{\ell+1}F(\rho) = \left[\tau F(\rho) - \frac{1}{4}\rho F(\rho)\right]e^{-\rho/2}\rho^{\ell} \quad (7.57)

$$

将式(7.55)~(7.57)代入(7.44)得

$$

\left[\rho \frac{d^2}{d\rho^2} + (2\ell + 2 - \rho) \frac{d}{d\rho} - (\ell + 1 - \tau)\right]F(\rho) = 0 \quad (7.58)

$$

利用级数展开法，令

$$

F(\rho) = \sum\_{i=0}^{\infty} c\_i \rho^i \quad (7.59)

$$

则

$$

F'(\rho) = \sum\_{i=0}^{\infty} i c\_i \rho^{i-1}, \qquad F''(\rho) = \sum\_{i=0}^{\infty} i (i-1) c\_i \rho^{i-2} \quad (7.60)

$$

故式(7.58)成为

$$

\sum\_{i=0}^{\infty} i (i-1) c\_i \rho^{i-1} + (2\ell + 2) \sum\_{i=0}^{\infty} i c\_i \rho^{i-1} - \sum\_{i=0}^{\infty} i c\_i \rho^{i} - (\ell+1-\tau) \sum\_{i=0}^{\infty} c\_i \rho^{i} = 0 \quad (7.61)

$$

或

$$

\sum\_{i=0}^{\infty} (i+1) i c\_{i+1} \rho^i + (2\ell + 2) \sum\_{i=0}^{\infty} (i+1) c\_{i+1} \rho^i - \sum\_{i=0}^{\infty} i c\_{i} \rho^i - (\ell+1-\tau) \sum\_{i=0}^{\infty} c\_{i} \rho^i = 0 \quad (7.62)

$$

$$

\sum\_{i=0}^{\infty} \left\{ \left[ (i+1) i + (2\ell + 2)(i+1) \right] c\_{i+1} - (i+\ell+1-\tau) c\_i \right\} \rho^i = 0 \quad (7.63)

$$

上式无穷级数对任意 $\rho$ 均成立，故唯一可能，是每一项之系数皆须为0，

即

$(i + 1)(i + 2\ell +2)c_{i + 1} - (i + \ell +1 - \tau)c_{i} = 0 \quad (7.64)$

得

$c_{i + 1} = \frac{i + \ell + 1 - \tau}{(i + 1)(i + 2\ell +2)} c_{i} \quad (7.65)$

当 $i \to \infty$ ，

$\frac{c_{i + 1}}{c_i} \approx \frac{i}{i^2} = \frac{1}{i} \quad (7.66)$

$u(\rho) = e^{-\rho /2}\rho^{\ell +1}F(\rho)\sim e^{-\rho /2}\rho^{\ell +1}e^{\rho} = e^{\rho /2}\rho^{\ell +1}\to \infty \quad (7.67)$

与边界条件 $u(r \to \infty) = 0$ 相抵触。由此可知， $F(\rho)$ 不能为一无穷级数，而必须为一有限的多项式，即必须终止于某一项，或

$c_{i + 1} = 0, \text{对某一整数} i \quad (7.68)$

由式(7.65)，故 $i + \ell +1 - \tau = 0$ ，即

$\tau = i + \ell +1 = n = \text{整数} \quad (7.69)$

且

$\ell \leq n - 1 \quad \text{或} \quad \ell = 0,1,2,\dots ,n - 1 \quad (7.70)$

因此

$\tau^2 \equiv \frac{1}{|E|} \cdot \frac{me^4}{2\hbar^2} = n^2 \quad (7.71)$

故氢或类氢原子系统之束缚能量（兹以 $Ze^2$ 代回 $e^2$ ）为

> [!equation] 类氢原子的束缚能级
> $\left|E\right| = \frac{Z^2}{n^2} \cdot \frac{me^4}{2\hbar^2} = \frac{Z^2\left|E_0\right|}{n^2} \quad (7.72)$

此值为特定之分离值或量子化值，而非任意连续值。

$k = R\left(\frac{1}{2^2} -\frac{1}{n^2}\right), \quad n = 3,4,5,\dots \quad (1.28)$

当时大多数的实验与理论均投注在放射线、原子及其谱线的探讨与分析上。热力学的黑体辐射与金属表面的光电效应，虽然指出了作用量新观念，但多数人以为那只是对电磁波与物质相互作用的一种描述，而完全无法想象，它与原子会有何关系。1913年，年轻的 Bohr 认为 Planck 与 Einstein 所言之作用量 $h$ ，有根本之深刻意涵，它应该遍布在所有微观现象之中，原子结构也应不例外。他利用了 Einstein 之光量子观念，再详视 Balmer 之谱线规则，大胆地提出其革命性的观念：定态（stationary state）、量子化（quantization）及跃迁（transition）。他假设：

> [!axiom] 玻尔的三条假设
> （一）核外的电子仅能存在于一些特定轨道，称之为稳定轨道或定态。
>
> （二）在任何包含有正电荷之原子核及其电子的分子系统里，…电子均以圆周轨道运动，而每个电子绕其轨道中心运动的角动量必须是 Planck 作用常数 $h$ 除上 $2\pi$ 的整数倍（称做角动量量子化）。
>
> $L = n\frac{h}{2\pi} = n\hbar \quad (n = 1,2,3,\dots) \quad (1.29)$
>
> （三）原子系统可以藉着吸收或放射出光辐射，而自一定态转换（或跃迁）至另一定态，此光辐射之频率 $\nu$ 由
>
> $E_{i} - E_{f} = h\nu \quad (1.30)$
>
> 决定，其中 $E_{i}$ 与 $E_{f}$ 为起初与后来之定态的能量， $E_{i} - E_{f}$ 为其能量差。

如此，对一电子在做圆周运动的氢原子而言，其向心力由库仑力提供

$m\frac{v^2}{r} = \frac{e^2}{r^2} \quad (1.31)$

或

$mv^2 = \frac{e^2}{r} \quad (1.32)$

此处 $e^2 = \frac{q^2}{4\pi\epsilon_0}$ ，另一方面由角动量 $L$ 与线动量 $mv$ 知

$\frac{e^2}{r} = mv^2 = \frac{(rmv)^2}{mr^2} = \frac{L^2}{mr^2} \quad (1.33)$

而可得到半径 $r$ 与角动量 $L$ 之关系

$r = \frac{L^2}{me^2} \quad (1.34)$

故氢原子系统内之总能量——动能与势能之和，由式（1.32）、（1.33）与（1.34）知

$E = \frac{1}{2} mv^2 -\frac{e^2}{r} = -\frac{1}{2} mv^2 = -\frac{L^2}{2mr^2} = -\frac{me^4}{2L^2} \quad (1.35)$

或

$E_n = -\frac{me^4}{2\hbar^2}\cdot \frac{1}{n^2} = -\frac{E_0}{n^2} \quad (1.36)$

此处

$E_0 = \frac{me^4}{2\hbar^2} = 13.6\ \mathrm{eV} \quad (1.37)$

所以 Balmer 光谱线系之波数 $k$

$k = \frac{1}{\lambda} = \frac{\nu}{c} = \frac{1}{hc} (E_i - E_f) = \frac{E_0}{hc} \left(\frac{1}{n_f^2} -\frac{1}{n_i^2}\right) \quad (1.38)$

若末态 $n_f = 2$ ，且

$\frac{E_0}{hc} = \frac{13.6\ \mathrm{eV}}{12400\ \mathrm{eV}\cdot\text{Å}} = 109677.6\ \mathrm{cm}^{-1} \quad (1.39)$

即为式(1.28)中之 Rydberg 常数，可以圆满地诠释氢原子光谱线。

玻尔成功地将黑体辐射作用量，与光电效应之光量子统合起来，应用在原子结构上，不论其设定与经典物理有多少的突兀，量子物理所开启的新纪元已不容再否定。

### 7.4 氢原子之体积与径向概率密度

若一实验所观测到的量，不是分离值而为连续值，譬如原子中电子所在之位置。则我们将无法像在处理对能量或角动量测量，可使用或明显指出电子位于某一能级或状态之概率的方法，来描述电子被测得在某一特定位置的概率（因位置不可被分割为有限的分离值）。而只能说电子被测得在某一小段位置的概率，或说在一特定位置上的概率密度。

> [!axiom] 量子公设四（连续且非简并的情况）
> 若对一个处于归一化状态 $|\phi \rangle$ 进行物理量 $A$ 的测量，则获得观测结果介于 $\alpha$ 和 $\alpha +d\alpha$ 之间的概率大小为
>
> $dP(\alpha) = |\langle u_{\alpha}|\phi \rangle |^2 d\alpha$
>
> 此处 $|u_{\alpha}\rangle$ 为对应于物理量 $A$ 可产生本征值为 $\alpha$ 的本征向量。

因概率之差分（differential）

$dP = |\langle u_{\alpha}|\phi \rangle |^2 d\alpha = \rho (\alpha)d\alpha \quad (7.80)$

则

$\rho (\alpha) = \frac{dP}{d\alpha} = |\langle u_{\alpha}|\phi \rangle |^2 \quad (7.81)$

代表质点被观测到介于 $\alpha$ 和 $\alpha +d\alpha$ 之概率，除以观测宽度 $d\alpha$ 之比值，又称之为概率密度（probability density）。

### 例7.2

在一维空间上状态为 $|\phi \rangle$ 之运动粒子，求此粒子被观测到位置介于 $x$ 与 $x + dx$ 之间的概率为何？

解 因给出位置观测结果为 $x$ 之本征态为 $|u_{\alpha}\rangle = |x\rangle$ ，由上述量子公设四，此粒子被观测到介于 $x$ 至 $x + dx$ 之间的概率为

$dP(x) = |\langle x|\phi \rangle |^2 dx = |\phi (x)|^2 dx$

或说此状态处在位置 $x$ 上之概率密度为 $\rho (x) = |\phi (x)|^2$ 。

## Ch7-7 氢原子的径向与体积概率密度(量子公设IV－连续状态的测量概率)

### 7.4 氢原子之体积与径向概率密度  

若一实验所观测到的量，不是分离值而为连续值，譬如原子中电子所在之位置。则我们将无法像在处理对能量或角动量测量，可使用或明显指出电子位于某一能级或状态之概率的方法，来描述电子被测得在某一特定位置的概率（因位置不可被分割为有限的分离值）。而只能说电子被测得在某一小段位置的概率，或说在一特定位置上的概率密度。  

> [!axiom] 量子公设四（连续且非简并的情况）
> 若对一个处于归一化状态 $|\phi \rangle$ 进行物理量 $A$ 的测量，则获得观测结果介于 $\alpha$ 和 $\alpha + d\alpha$ 之间的概率大小为
>
> $$dP(\alpha) = \left|\langle u_{\alpha}|\phi \rangle \right|^2 d\alpha$$
>
> 此处 $\left|u_{\alpha}\right\rangle$ 为对应于物理量 $A$ 可产生本征值为 $\alpha$ 的本征向量。

因概率之差分（differential）  

$$dP = \left|\langle u_{\alpha}|\phi \rangle \right|^2 d\alpha = \rho (\alpha)d\alpha \quad (7.80)$$  

则  

$$\rho (\alpha) = \frac{dP}{d\alpha} = \left|\langle u_{\alpha}|\phi \rangle \right|^2 \quad (7.81)$$  

代表质点被观测到介于 $\alpha$ 和 $\alpha + d\alpha$ 之概率，除以观测宽度 $d\alpha$ 之比值，又称之为概率密度（probability density）。  

### 例7.2  

在一维空间上状态为 $|\phi \rangle$ 之运动粒子，求此粒子被观测到位置介于 $x$ 与 $x + dx$ 之间的概率为何？  

解 因给出位置观测结果为 $x$ 之本征态为 $\left|u_{\alpha}\right\rangle = \left|x\right\rangle$ ，由上述量子公设四，此粒子被观测到介于 $x$ 至 $x + dx$ 之间的概率为  

$$dP(x) = \left|\langle x|\phi \rangle \right|^2 dx = \left|\phi (x)\right|^2 dx$$  

或说此状态处在位置 $x$ 上之概率密度为 $\rho (x) = \left|\phi (x)\right|^2$ 。

例.7.3. 

一状态为 $|\varphi\rangle$ 在直线上运动之粒子，求观测到此粒子介于 0 至 $a$ 之间的概率为多少? 

解 由于观测到粒子介于 0 至 $a$ 之间的概率 $P(0 \le x \le a)$, 为观测到粒子在 $x$ 至 $x+dx$ 之间的概率 $dP(x)$ 之总和, 其中 $0 \le x \le a$, 即 

$$P(0 \le x \le a) = \int_{P(0)}^{P(a)} dP(x) = \int_{0}^{a} |\langle x | \varphi \rangle|^2 dx = \int_{0}^{a} |\varphi(x)|^2 dx$$

例.7.4. 

一状态为 $|\varphi\rangle$ 在三维空间运动之粒子，求在 $x$ 轴上之 $[x_1, x_2]$ 区间中，发现此粒子的概率为何? 

解 找到此粒子介于 $x_1 \le x \le x_2$, 而在 $y$ 与 $z$ 上不受限制, 其概率为 

$$$

\begin{align\*}
P(x\_1 \le x \le x\_2) &= P(x\_1 \le x \le x\_2, -\infty \le y \le \infty, -\infty \le z \le \infty) \\
&= \int\_{x\_1}^{x\_2} dP(x, y, z) = \int\_{x\_1}^{x\_2} \int\_{-\infty}^{\infty} \int\_{-\infty}^{\infty} |\langle x, y, z | \varphi \rangle|^2 dz, dy, dx \\
&= \int\_{x\_1}^{x\_2} \int\_{-\infty}^{\infty} \int\_{-\infty}^{\infty} |\varphi(x, y, z)|^2 dz, dy, dx
\end{align\*}

$$$

例.7.5. 

在时间 $t=0$ 时, 有 1000 个中子局限在 $10^{-5}$ 厘米的一维空间里, 其中有 100 个中子的能量处于 $4E_1$, 900 个中子的能量携带 $225E_1$, $E_1$ 为基态的能量。 

(a) 建立一个具有上述性质之中子的状态函数。 

(b) 有多少个中子会在此空间的左半边? 

解 假设所有的中子都在 0 到 $a=10^{-5}$ 厘米之间运动, 则由式知可能之能级与波函数为 

$$ E_n = \frac{\pi^2 \hbar^2}{2ma^2} n^2 = n^2 E_1, \quad \varphi_n = \sqrt{\frac{2}{a}} \sin \frac{n\pi x}{a} $$

(a) 能量为 $4E_1$ 与 $225E_1$ 的中子，分别代表处在 $n=2$ 与 $n=15$ 之状态，其出现概率分别为 $1/10$ 与 $9/10$ ，故其中任一中子的状态函数，由量子公设四，得  

$$\phi (x) = \sqrt{\frac{1}{10}}\sqrt{\frac{2}{a}}\sin \frac{2\pi}{a} x + \sqrt{\frac{9}{10}}\sqrt{\frac{2}{a}}\sin \frac{15\pi}{a} x$$  

(b) 出现在左半边之概率为各点概率点之总和或积分，即  

$$$

\begin{aligned}
P\left(0\leq x\leq \frac{a}{2}\right) &= \int\_{0}^{a / 2}|\phi (x)|^{2}d x\\
&= \frac{1}{10\pi}\int\_{0}^{a / 2}\sin^{2}\frac{2\pi}{a} x, d\left(\frac{2\pi}{a} x\right) + \frac{6}{5\pi}\int\_{0}^{a / 2}\sin \frac{2\pi}{a} x\sin \frac{15\pi}{a} x, d\left(\frac{\pi}{a} x\right)\\
&\quad +\frac{9}{5\pi}\int\_{0}^{a / 2}\sin^{2}\frac{15\pi}{a} x, d\left(\frac{\pi}{a} x\right) = \frac{1}{20} +\frac{3}{5\pi}\left\[\frac{1}{13} -\frac{1}{17}\right] + \frac{9}{20}\cong 0.5
\end{aligned}

$$$

对于在三维空间中运动的质点，如原子中之电子，当对它从事某一物理量（如位置）之观测结果为连续值时，由量子公设四，所能明白掌握的是概率差分 $dP(r,\theta ,\phi)$ ，而观测到出现在较大范围的概率，则为此概率差分之和，即  

$$P = \int dP \quad (7.82)$$  

若欲求得电子出现在体积范围 $\Delta V$ 之概率，由例7.4则为  

$$P = \int_{\Delta V}dP(r,\theta ,\phi) = \int_{\Delta V}|\langle r,\theta ,\phi |\psi \rangle |^2 dV = \int_{\Delta V}\int_{\Omega}|\psi (r,\theta ,\phi)|^2 d\Omega\, r^2 dr \quad (7.83)$$  

另一方面，由体积概率密度（probability volume density） $\rho_{V}$ 之定义  

$$\rho_{V} = \frac{dP}{dV} \quad (7.84)$$  

及概率差分 $dP$ 之意义，有  

$$P = \int_{\Delta V}dP = \int_{\Delta V}\frac{dP}{dV} dV = \int_{\Delta V}\rho_{V}dV = \int_{\Delta V}\rho_{V}r^{2}dr\, d\Omega \quad (7.85)$$

比较式(7.83)与(7.85), 故体积概率密度 

$$ \rho_V = \frac{dP}{dV} = |\psi(r, \theta, \varphi)|^2 \quad (7.86) $$

对类氢原子中处于某一定态之电子而言, 由式(7.76), 则为 

$$ \rho_V = |R(r)Y_\ell^m(\theta, \varphi)|^2 \quad (7.87) $$

**代表此电子出现在体积范围** $\Delta V = r^2 dr d\Omega$ **之概率大小, 除上其体积值** $\Delta V$, 如式(7.84)所示。 

而由径向概率密度 (Probability radial density) $\rho_r$ 之定义 

$$ \rho_r = \frac{dP}{dr} \quad (7.88) $$

及概率差分 $dP$ 之意义, 

$$ P = \int_{\Delta V} dP = \int_{\Delta V} \frac{dP}{dr} dr = \int_{\Delta V} \rho_r dr \quad (7.89) $$

比较式(7.83)与(7.89), 故径向概率密度 

$$ \rho_r = \frac{dP}{dr} = r^2 \int_{\Omega} |\psi(r, \theta, \varphi)|^2 d\Omega \quad (7.90) $$

对类氢原子中处于某一定态之电子而言, 则为 

$$$

\begin{aligned} \rho\_r &= r^2 \int\_{\Omega} |R(r)Y\_\ell^m(\theta, \varphi)|^2 d\Omega \ &= r^2 |R(r)|^2 \int\_{\Omega} |Y\_\ell^m(\theta, \varphi)|^2 d\Omega = r^2 |R(r)|^2 = |u(r)|^2 \end{aligned} \quad (7.91)

$$$

**代表此电子出现在半径范围在** $r$ **至** $r + \Delta r$ **(或落在由半径** $r$ **至半径** $r + \Delta r$ **之球壳内)的概率值, 除以其厚度** $\Delta r$ **。**

氢原子波函数(概率密度) 

$$ \psi_{n\ell m}(r, \theta, \varphi) = \sqrt{\left(\frac{2}{na_0}\right)^{3} \frac{(n-\ell-1)!}{2n[(n+\ell)!]^{3}}}\; e^{-\rho/2} \rho^\ell L_{n-\ell-1}^{2\ell+1}(\rho) \cdot Y_{\ell m}(\theta, \varphi) $$

### 7.5 有解习题

### 问题7.1

今有一类氢原子的波函数为

$$\psi (r,\theta) = \frac{1}{18}\sqrt{\frac{2}{\pi}} Z^{3 / 2}(6 - Zr)Zre^{-Zr / 3}\cos \theta$$

其中 $r$ 是以 $a_0$ 为单位

(a) 求出各量子数 $n$、$\ell$ 和 $m$ 的值

(b) 由 $\psi (r,\theta)$ 建立另一个波函数，具有相同的 $n\ell$，但磁量子数为 $m + 1$。

(c) 对处于状态 $\psi$ 且 $Z = 1$ 的电子而言，若只问径向距离，求此电子最可能出现在何处？

解：(a) 因 $\psi (r,\theta ,\phi)$ 的指数部分均具有 $e^{- Zr / n}$（若 $r$ 是以 $a_0$ 为单位）的型式，故由 $e^{- Zr / 3}$ 可知此状态处于 $n = 3$，而角动量量子数 $\ell$，可由 $\hat{L}^2$ 作用在 $\psi (r,\theta)$ 上后，得

$$$

\begin{aligned} \hat{L}^2\psi (r,\theta) & = \hat{L}^2 f(r)\cos \theta = \hbar^2 f(r)\left(-\frac{1}{\sin\theta}\frac{\partial}{\partial\theta} \left(\sin\theta\frac{\partial}{\partial\theta}\cos \theta\right)\right) \ & = \hbar^2 f(r)\left(\frac{1}{\sin\theta}\frac{d}{d\theta} (\sin \theta)^2\right) = 2\hbar^2 f(r)\cos \theta = \ell (\ell +1)\hbar^2\psi (r,\theta) \end{aligned}

$$$

故 $2 = \ell (\ell +1)$ 或 $\ell = 1$。

磁量子数 $m$，则利用 $\hat{L}_z$ 作用在 $\psi (r,\theta)$ 后，得

$$\hat{L}_z\psi (r,\theta) = -i\hbar \frac{\partial}{\partial\phi} (f(r)\cos \theta) = 0 = m\hbar \psi (r,\theta)$$

$$m = 0\therefore \hat{L}_+\psi_m = \sqrt{(\ell - m)(\ell + m + 1)}\psi_{m + 1} = \sqrt{2}\psi_{m + 1}$$

(b) 若要建立一个新的类氢原子，且磁量子数为 $m + 1$ 的波函数，我们可以利用上升算符 $\hat{L}_+$ 来处理。因为 $\ell = 1$，$m = 0$

$$\hat{L}_+\psi_m = \sqrt{(\ell - m)(\ell + m + 1)}\hbar \psi_{m + 1}(r,\theta) = \sqrt{2}\hbar \psi_{m + 1}(r,\theta)$$

$$\hat{L}_+ = \hat{L}_x + i\hat{L}_y = i(\sin \phi -i\cos \phi)\frac{\partial}{\partial\theta} +i\hbar (\cos \phi +i\sin \phi)\cot \theta \frac{\partial}{\partial\phi}$$

$$\hat{L}_+\psi_{m = 0} = \hbar e^{i\phi}\frac{\partial}{\partial\theta} f(r)\cos \theta = -\hbar e^{i\phi}f(r)\sin \theta$$
